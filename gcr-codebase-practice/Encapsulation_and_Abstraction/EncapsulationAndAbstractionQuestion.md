# Encapsulation and Abstraction Question

Create an abstract class named `Vehicle` with the following requirements:

- Use encapsulation for private fields such as `vehicleId`, `brand`, and `basePrice`.
- Provide public getters and setters for each field.
- Add a concrete method to display the vehicle details.
- Declare an abstract method named `calculateTax()`.

Create two subclasses:

- `Car` with a tax rate of `12%`
- `Bike` with a tax rate of `8%`

In the `main` method:

- Create one `Car` object and one `Bike` object.
- Display their details.
- Print the calculated tax for each vehicle.

Requirements:

- Use abstraction through the abstract class and abstract method.
- Use `@Override` in the subclasses.
- Keep the code clean and easy to understand.
