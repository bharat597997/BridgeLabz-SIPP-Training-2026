# Inheritance Assignment

Create a Java program to demonstrate inheritance using a real-world example.

## Problem Statement

Design a base class named `Person` with the following attributes:
- `name`
- `age`

Add a method to display the person's basic details.

Create a derived class named `Student` that inherits from `Person` and adds:
- `studentId`
- `course`

Add a method to display the student's details.

Create another derived class named `Teacher` that inherits from `Person` and adds:
- `employeeId`
- `subject`

Add a method to display the teacher's details.

## Requirements
- Use inheritance properly.
- Use `extends` keyword.
- Use `super()` in the child class constructors.
- Override or reuse methods appropriately.
- Demonstrate object creation for both `Student` and `Teacher`.

## Expected Output
- Display the details of the student.
- Display the details of the teacher.
